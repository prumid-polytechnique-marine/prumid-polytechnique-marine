PUBLICATION SUR GITHUB PAGES
1. Décompresser cette archive sur l’ordinateur.
2. Ouvrir le dépôt GitHub prumid-polytechnique-marine et vérifier la branche main.
3. Choisir Add file > Upload files.
4. Téléverser le contenu décompressé, en conservant tous les fichiers dans la racine du dépôt. Ne pas téléverser uniquement le ZIP.
5. Valider les modifications sur main, puis attendre la publication GitHub Pages.
6. Recharger le site avec Ctrl+F5.

DROITS SUR LES VISUELS
Plusieurs nouvelles images sont des visuels d’illustration issus de fichiers dont le nom indique iStock. Elles sont signalées dans les légendes. Avant publication commerciale, vérifier que PRUMID dispose des licences nécessaires ou remplacer ces visuels par des photos originales / libres de droits. L’image contenant un filigrane iStock et l’image publicitaire d’une autre entreprise n’ont pas été intégrées.
