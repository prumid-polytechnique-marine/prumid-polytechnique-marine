PRUMID POLYTECHNIQUE MARINE SARL — VERSION 12

Cette version enrichit la galerie du site avec des photos de terrain fournies dans la conversation et quatre vidéos optimisées pour le web.

Nouveautés :
- Photo du pupitre CAT et de l’ordinateur de diagnostic ;
- Photo d’un compresseur mobile ;
- Photos de moteurs marins in-bord et de compartiments moteur ;
- Photos de terrain en environnement portuaire et en tenue PRUMID ;
- Quatre séquences vidéo supplémentaires sur le diagnostic et l’inspection d’un groupe électrogène ;
- Vignettes vidéo optimisées ;
- Images intégrées à la galerie terrain et aux rubriques d’expertise concernées.

Publication GitHub Pages :
1. Décompresser cette archive sur l’ordinateur.
2. Ouvrir le dépôt GitHub PRUMID sur la branche main.
3. Cliquer sur Add file > Upload files.
4. Téléverser le contenu extrait à la racine du dépôt (ne pas téléverser uniquement le ZIP).
5. Remplacer les fichiers de même nom, notamment index.html et styles.css, puis valider avec un message tel que :
   Version 12 — ajout photos de terrain et vidéos de maintenance
6. Attendre le déploiement GitHub Pages, puis recharger le site avec Ctrl+F5.

Les quatre nouvelles vidéos ont été recompressées pour réduire leur poids. La vidéo commerciale en espagnol avec le numéro d’un vendeur tiers n’a pas été ajoutée.

Cette archive contient les fichiers du site ; elle ne publie pas elle-même les changements sur GitHub.
