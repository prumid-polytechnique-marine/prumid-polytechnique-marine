PUBLICATION SUR GITHUB PAGES
1. Téléchargez et décompressez le ZIP.
2. Ouvrez le dépôt GitHub du site PRUMID.
3. Choisissez Add file > Upload files.
4. Téléversez les fichiers et dossiers à l’intérieur du ZIP à la racine du dépôt (pas le ZIP lui-même).
5. Remplacez les fichiers existants lorsqu’il vous le demande.
6. Commit changes sur la branche principale.
7. Attendez le déploiement GitHub Pages, puis actualisez le site avec Ctrl+F5.

Cette archive prépare les fichiers mais ne publie pas automatiquement le site sur GitHub.
