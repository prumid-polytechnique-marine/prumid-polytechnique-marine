## Publication gratuite avec GitHub Pages
1. Créez un compte GitHub si nécessaire.
2. Créez un nouveau dépôt nommé par exemple `prumid-site`.
3. Téléversez les 4 fichiers du dossier du site.
4. Ouvrez Settings > Pages.
5. Dans Build and deployment, choisissez "Deploy from a branch".
6. Sélectionnez la branche `main` et le dossier `/root`, puis enregistrez.
7. GitHub vous donnera une adresse publique gratuite.

## Autre option
Vous pouvez aussi déposer le dossier sur Netlify Drop pour obtenir rapidement une adresse gratuite.
