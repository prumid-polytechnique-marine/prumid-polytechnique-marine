PUBLICATION SUR GITHUB PAGES
1. Décompresser le ZIP.
2. Ouvrir le dépôt GitHub PRUMID et sélectionner la branche main.
3. Cliquer sur Add file > Upload files.
4. Téléverser tous les fichiers et dossiers contenus dans cette archive, à la racine du dépôt. Ne pas téléverser uniquement le ZIP.
5. Remplacer les fichiers de même nom, notamment index.html, styles.css et logo-prumid.jpg.
6. Valider avec le message : Version 13 — nouveau logo et photos de terrain.
7. Attendre le déploiement GitHub Pages puis actualiser le site avec Ctrl+F5.

NOTES
- Les fichiers sont préparés, mais cette archive ne publie pas elle-même les changements sur GitHub.
- L’illustration « prumid-illustration-maintenance-marine.webp » est identifiée comme illustration graphique, pas comme photographie d’une intervention réelle.
- Avant publication commerciale, vérifier les droits d’utilisation des visuels illustratifs déjà présents dans les versions antérieures.
- Les nouvelles photos de moteur et du site portuaire sont présentées descriptivement, sans affirmer une prestation ou un résultat non documenté.
- La consigne de ne pas afficher publiquement le nom personnel ni la fonction privée précédemment signalés est conservée.
