PUBLICATION SUR GITHUB PAGES
1. Téléchargez et décompressez le fichier ZIP.
2. Ouvrez le dépôt GitHub du site PRUMID.
3. Cliquez sur « Add file » puis « Upload files ».
4. Téléversez tous les fichiers et dossiers contenus dans le ZIP décompressé, pas le ZIP lui-même.
5. Remplacez les fichiers du même nom si GitHub le demande.
6. Dans le message de commit, indiquez : « Version 10 — ajout illustration bateaux et vidéo groupe électrogène ».
7. Validez les changements sur la branche principale (« main »).
8. Attendez la publication GitHub Pages, puis rechargez le site avec Ctrl+F5.

Important : ce paquet prépare les fichiers du site. Il ne publie pas automatiquement les changements sur GitHub.
